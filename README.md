# React Notes App

A simple Notes App built with React.js and Tailwind CSS to practice React fundamentals, including form handling, two-way binding, state management, and dynamic rendering.

## About the Project

This project allows users to create and delete notes through a simple user interface. Users can enter a heading and details, add the note to the list, and remove notes when they are no longer needed.

The main goal of this project was to understand how React handles user input, manages component state, and updates the UI dynamically.

## Features

- **Add Notes:** Create notes with a heading and description.
- **Delete Notes:** Remove a specific note from the list.
- **Controlled Inputs:** Manage input and textarea values using React state.
- **Dynamic Rendering:** Display notes dynamically as they are added.
- **Responsive UI:** Adapt the layout for different screen sizes.
- **Interactive Interface:** Simple buttons, input fields, and note cards.

## Concepts Learned

### 1. Form Handling
Used the `onSubmit` event to handle form submission and `preventDefault()` to prevent the browser from reloading the page.

### 2. Two-Way Binding
Connected input fields and the textarea to React state using the `value` and `onChange` properties, keeping the UI synchronized with the state.

### 3. useState Hook
Used React's `useState` Hook to store input values and maintain the list of notes.

### 4. Event Handling
Implemented `onChange`, `onSubmit`, and `onClick` events to handle user interactions.

### 5. State Management
Used state updates to add new notes and remove existing notes from the application.

### 6. Array Operations
Practiced the spread operator (`...`), `push()`, and `splice()` to manage the notes array.

### 7. Dynamic Rendering with map()
Used the JavaScript `map()` method to render note cards dynamically from the array stored in React state.

### 8. Conditional UI Updates
React automatically updates the displayed notes when the state changes after adding or deleting a note.

### 9. Component-Based Development
Built the application UI using JSX and React component structure.

### 10. Tailwind CSS
Used utility classes for layout, spacing, colors, borders, responsive design, and interactive styling.

## Tech Stack

- **React.js** – UI development and state management
- **JavaScript (ES6+)** – Event handling and array operations
- **Tailwind CSS** – Styling and responsive layouts
- **Vite** – Development server and build tool
